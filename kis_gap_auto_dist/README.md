파이썬 설치 없이 바로 실행 가능한 **독립 실행형 윈도우 프로그램**입니다.

```

```

---

## 🔑 1단계: API 키 설정 (필수)

`kis_secret.json` 파일을 메모장으로 열어서 본인의 한국투자증권(KIS) API 정보를 입력하고 저장합니다.

```json
{
    "APP_KEY": "발급받은 앱 키를 여기에 입력",
    "APP_SECRET": "발급받은 시크릿 키를 여기에 입력",
    "CANO": "계좌번호 앞 8자리",
    "ACNT_PRDT_CD": "01",
    "URL_BASE": "https://openapi.koreainvestment.com:9443"
}
```

> ⚠️ **모의투자** 테스트를 원하시면 `URL_BASE`를 아래 주소로 변경하세요:
> `https://openapivts.koreainvestment.com:29443`

> 🔑 **API 키 발급:** [KIS Developers](https://apiportal.koreainvestment.com) 접속 → 앱 등록 → 앱키/시크릿키 확인

---

## ▶️ 2단계: 프로그램 실행

### 🤖 자동매매 봇 시작
**`gap_stock_auto.exe`** 를 더블클릭합니다.

- 검은색 터미널 창이 열리며 계좌 잔액을 확인한 후 봇이 시작됩니다.
- 장이 열려있는 동안 **이 창을 닫으면 자동매매가 중단됩니다.**
- 오후 3시 15분에 매수 탐색, 매 10분마다 보유 종목 매도 조건을 검사합니다.

### 📊 실시간 모니터링
**`kis_gui.exe`** 를 더블클릭합니다.

- 현재 보유 종목, 매수 단가, 수익/손절 라인을 한눈에 확인할 수 있습니다.
- 10초마다 자동 갱신됩니다. 봇과 독립적으로 켜고 끌 수 있습니다.

## 💡 전략 요약

| 항목 | 내용 |
|---|---|
| 투자 비중 | 총 자산의 25% × 최대 4종목 분산 |
| 매수 조건 | MA120선 위 우량주 + 연속 갭하락 + 전일비 -5% 초과 |
| 익절 방식 | 갭메우기(전일 저가)에서 50% 익절 → 나머지 MA5 이탈 시 전량 매도 |
| 손절 방식 | 매수가 대비 -10% 도달 시 즉시 손절 / 20일 이상 보유 시 강제 청산 |
| 종목 필터 | 부채비율 200% 이상 기업 제외 / 금융주는 PBR 0.5 이하만 허용 |
